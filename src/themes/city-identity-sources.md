# City lettering and icon tags

`cityIdentity.js` keeps a written local or regional name for each city. It is deliberately city-specific: Darjeeling's hill towns use Nepali, Silchar uses Bengali, and the Jammu stops use Dogri. Multilingual places have one representative written form, not a claim that the place has only one language. Urdu is used for several Kashmir and Kargil names; Srinagar uses Kashmiri. Itanagar uses the established Hindi form. Roman-script names remain Roman; Kohima uses Kewhira.

The English heading remains the accessible page title. The secondary lettering is decorative, carries its language and direction, and has no container fill or border. Fonts use local script-aware fallbacks; no translation service or font request runs at page load.

References consulted for regional choices and less familiar spellings:

- [Coimbatore district, Tamil](https://coimbatore.nic.in/ta/): கோயம்புத்தூர்.
- [Akashvani Kurseong, Nepali bulletin](https://www.newsonair.gov.in/wp-content/uploads/2025/10/kurseong-1850-3.pdf): दार्जिलिङ, खरसाङ, मिरिक and कालिम्पोङ.
- [Gangtok district](https://gangtokdistrict.nic.in/): local languages include Nepali.
- [Kohima district history](https://kohima.nic.in/hi/जिले-के-बारे-में/): Kewhira.
- [Tawang district language notes](https://tawang.nic.in/language/): Monpa and the local use of Bhoti; [Tawang spelling](https://en.wikipedia.org/wiki/Tawang).
- [Srinagar native labels](https://www.wikidata.org/wiki/Q15722530): Kashmiri سِریٖنَگَر.
- [Kargil Department of Information's bilingual magazine](https://cdnbbsr.s3waas.gov.in/s395192c98732387165bf8e396c0f2dad2/uploads/2023/11/2023110890274849.pdf): کرگل.
- [Leh place-name reference](https://placenameswallah.com/ladakh/): གླེ.
- [Srinagar Mail's local Urdu reporting](https://srinagarmail.com/2025/07/09/18316/): سونہ مرگ and بال تل.
- [NIELIT Itanagar](https://www.nielit.gov.in/itanagar/hi/node/3636): ईटानगर.

Each tag row starts with the city's existing theme symbol and a short character label. Existing category tags follow, with duplicates removed and the total capped at six. Category tags retain navigation to the category index. A city without categories still receives its character tag. The native-name and tag-count checks cover all 128 city records, while the static-artwork check verifies their placement in every generated city page.
